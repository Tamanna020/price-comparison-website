## 🔬 Ingredient Analysis

### How to Use
1. Go to any **Product Detail Page**
2. Click the **"Analyze Ingredients"** button (in the product info section)
3. View the detailed breakdown

### What You'll See

| Section | Description |
|---------|-------------|
| **Key Actives** | Most important active ingredients highlighted |
| **Ingredient Cards** | Each ingredient with function, benefits, concerns |
| **Compatibility** | What works well together / what to avoid |
| **Routine Compatibility** | Which ingredients suit AM vs PM |
| **Potential Conflicts** | Scientifically documented ingredient conflicts |

### Understanding Source Badges

| Badge | Meaning |
|-------|---------|
| 🟢 **AI ANALYZED** | Generated by Gemini AI (most detailed) |
| 🟡 **BASIC ANALYSIS** | Heuristic fallback (when AI unavailable) |
| 🔴 **NO DATA** | No ingredient information available |

> **⚠️ Note:** Basic analysis only shows ingredients listed in product specs. AI analysis provides deeper explanations.

### Example: Vitamin C Serum
```
🟢 AI ANALYZED
Key Actives: Vitamin C (L-Ascorbic Acid), Ferulic Acid, Vitamin E

Ingredient Cards:
• Vitamin C — Antioxidant — Brightens, boosts collagen, fades dark spots
  ✅ Works with: Vitamin E, Ferulic Acid, Hyaluronic Acid
  ❌ Avoid with: Retinol (use at different times), Benzoyl Peroxide
  ⚠️ Concerns: May irritate sensitive skin, oxidizes quickly

• Hyaluronic Acid — Humectant — Hydrates, plumps skin
  ✅ Works with: Everything
  ❌ Avoid with: Nothing
```

## 💰 Cheaper Alternatives / Dupe Finder

### How to Use
1. On any **Product Detail Page**, click **"Find Alternatives"**
2. Adjust settings (optional):
   - **Max Price Ratio:** Default 80% (shows products ≤80% of original price)
   - **Min Similarity:** Default 60% (how similar ingredients/formulation must be)
3. Click **"Search Alternatives"**

### Results Explained

| Field | Meaning |
|-------|---------|
| **Original Product** | Your reference product with price |
| **Alternative** | Suggested dupe with price |
| **Price Difference** | How much you save |
| **Similarity Score** | 0-100% ingredient/formulation match |
| **Matched Attributes** | What's the same (brand, ingredients, type) |
| **Key Differences** | Important differences (size, formulation, actives %) |
| **Suitability** | Overall recommendation score |
| **Price Verified** | ✅ Both prices verified / ⚠️ One or both unverified |

### Important Guidelines

> **⚠️ Never assume products are identical just because they share ingredients.**
> - Concentration matters (10% vs 1% Vitamin C)
> - Formulation matters (water-based vs oil-based)
> - pH matters for actives (Vitamin C needs low pH)
> - Supporting ingredients affect stability and penetration

### Example: The Ordinary Niacinamide 10% + Zinc 1% (₹590)
```
Alternative: Minimalist 10% Niacinamide + Zinc (₹525)
  Savings: ₹65 (11%) | Similarity: 95%
  Matched: Niacinamide 10%, Zinc 1%, Water-based serum
  Differences: Minimalist adds Hyaluronic Acid for hydration
  Suitability: 93% | ✅ PRICE VERIFIED

Alternative: Good Molecules Niacinamide Serum (₹780)
  Savings: -₹190 (more expensive) | Similarity: 88%
  Matched: Niacinamide 10%, similar texture
  Differences: Different preservative system, no Zinc
  Suitability: 75% | ⚠️ PRICE UNVERIFIED
```

## 🌅 Routine Builder (AM/PM)

### How to Use
1. Go to **My Routines** page
2. Click **"Generate Routine"** 
3. Fill in:
   - **Skin Type:** Normal, Dry, Oily, Combination, Sensitive
   - **Concerns:** Select all that apply
   - **Routine Type:** AM (morning) or PM (evening)
   - **Existing Products:** Optionally add products you already own
   - **Budget:** Optional price range
4. Click **"Generate My Routine"**

### AM Routine Structure
```
1. CLEANSE → Gentle cleanser (remove overnight oils)
2. TONE → Hydrating/balancing toner (prep skin)
3. TREAT → Active serums (Vitamin C, Niacinamide, etc.)
4. MOISTURIZE → Day cream (lightweight, barrier support)
5. SUNSCREEN → SPF 30+ (NON-NEGOTIABLE)
```

### PM Routine Structure
```
1. CLEANSE → Gentle cleanser (remove sunscreen, makeup, pollution)
2. TONE → Hydrating toner (prep for actives)
3. TREAT → Active serums (Retinol, AHAs/BHAs, Peptides)
4. MOISTURIZE → Night cream (richer, repair-focused)
```

### What You'll See

| Element | Description |
|---------|-------------|
| **Step Order** | Numbered in correct application sequence |
| **Product Recommendations** | Specific products from catalog (or generic if none match) |
| **Key Ingredients** | What to look for in each step |
| **Frequency** | Daily / 2-3x week / As needed |
| **Usage Instructions** | How to apply correctly |
| **Precautions** | Warnings (e.g., "Patch test first", "Avoid eye area") |
| **Patch Test Items** | Products requiring patch test highlighted |
| **Conflicts** | Ingredient conflicts flagged (e.g., Retinol + Vitamin C) |
| **Total Estimated Cost** | Sum of recommended products (if budget set) |

### Smart Features

| Feature | Description |
|---------|-------------|
| **Ingredient Conflict Detection** | Warns about Retinol + Vitamin C, Benzoyl Peroxide + Retinoids, etc. |
| **Sunscreen Enforcement** | AM routines always include sunscreen step |
| **Patch Test Guidance** | Flags new actives (Retinol, Vitamin C, Acids) |
| **Budget Respect** | Tries to stay within your price range |
| **Existing Product Integration** | Incorporates products you already own |

## ❓ Frequently Asked Questions

### Q: Does this work without an AI API key?
**A:** Yes! All features have **heuristic fallbacks** that work offline. You'll see 🟡 BASIC ANALYSIS badges instead of 🟢 AI ANALYZED.

### Q: Is my data sent to Google?
**A:** Only product information (ingredients, specs) is sent to Gemini. **No personal data, no API keys in frontend.** All calls are backend-only.

### Q: Can I trust the routine recommendations?
**A:** They're **suggestions based on cosmetic science**, not medical advice. Always patch test new actives. Consult a dermatologist for medical conditions.

### Q: Why are some prices marked "UNVERIFIED"?
**A:** Price Verified = both original and alternative prices come from live retailer data. Unverified = at least one price is from demo/cached data.

### Q: Can I use this for medical skin conditions?
**A:** No. This is for **cosmetic product selection only**. Not a substitute for dermatologist advice.

### Q: What if I hit the rate limit?
**A:** Wait until midnight UTC, or contact support if you need higher limits.

## 🛠️ Troubleshooting

| Issue | Solution |
|-------|----------|
| "AI service unavailable" | Features still work with BASIC ANALYSIS fallback |
| "Rate limit exceeded" | Wait until midnight, or reduce usage |
| No alternatives found | Lower similarity threshold or increase max price ratio |
| Routine missing products | Add more products to catalog, or use generic recommendations |
| Ingredient analysis empty | Product may not have "Key Ingredients" in specs |
